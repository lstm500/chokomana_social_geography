# ちょこまな｜しゃかい・ちり　都道府県たんけん

1回につき1つの都道府県を探検します。全国または地方を選ぶと、県名が付いていないピースが出ます。ドラッグ、またはピースと地図の順にタップして、日本地図にはめます。

ピースがはまると地図が拡大します。県名と都道府県庁所在地を確認し、地図上のしるしで代表的な地形や産業・特産品を開きます。その土地の気候、水や土地の使い方が、産業につながる理由を学びます。理由を問う問題は、まず自分の言葉で説明してから選択肢で答えます。

| 年齢 | 1回のクイズ |
|---|---:|
| 6歳以下 | 2問 |
| 7歳 | 4問 |
| 8〜9歳 | 6問 |
| 10歳 | 8問 |
| 11歳以上 | 10問 |

最後のクイズは全問正解で金、1問でも不正解なら銀です。ピースの置き直しはメダルに影響しません。集約アプリの年齢を引き継ぎ、年齢設定がない場合はアプリ内で選べます。

## GitHub・Supabase・Streamlit

地理用のGitHubリポジトリのルートに `app.py`、`README.md`、`requirements.txt` を置きます。画面、地図データ、教材、学習記録の処理は `app.py` に入っています。

1. 既存のちょこまなと同じSupabaseプロジェクトのSQL Editorで、`001_geography.sql` を適用します。前版を適用済みの場合も、今回のSQLを適用します。
2. 地理アプリをStreamlitで公開します。起動ファイルは `app.py` です。サーバーのSecretsに `SUPABASE_URL`、`SUPABASE_SERVICE_ROLE_KEY` または `SUPABASE_SECRET_KEY`、`CHOKOMANA_HOME_URL` を設定します。
3. 集約アプリのリポジトリに、ZIP内の別フォルダーの `hub/app.py` を配置します。集約アプリのSecretsの `GEOGRAPHY_APP_URL` に地理アプリのHTTPS URLを入れます。
4. 地理アプリを一度開き、新しい教材一覧を登録します。集約アプリの「しゃかい・ちり」から地方を選び、最後まで解くと「地」メダルが「今日の成果」に出ます。地方別の探検は「きょう やること」の候補に入り、全国から選ぶコースは自由学習です。すでにその日の課題が確定している場合、新コースの自動選定は翌日からです。

単独で試すには `pip install -r requirements.txt` の後、`streamlit run app.py` を実行します。単独利用では、コース選択画面から端末の記録をJSONで出力できます。

## 学習ログ

共通の `chokomana_learning_events` と `chokomana_stamps` に、`source_app = 'geography'` として保存します。学習イベントにはピースの配置、ヒント、地図で開いた特徴、問題ID、初回回答の正誤、学習時間が含まれます。クイズの正誤は、教材を見た後の確認結果です。

同じブラウザで途中から再開できます。前版の完了済み記録と未同期の記録は保持します。前版で途中だったコースはJSON出力に残ります。

## 教材の出典

- 都道府県の輪郭は国土地理院「地球地図日本」を [Data of Japan](https://github.com/dataofjapan/land) の変換データから加工しました。輪郭を簡略化し、一部の島を省略しています。沖縄は全国地図の別枠に拡大表示しています。
- 地名と地形は [地理院地図](https://maps.gsi.go.jp/) を参照し、都道府県庁の位置は Data of Japan の都道府県庁所在地座標を使用しています。
- 産業・特産品の資料は [農林水産省「都道府県の農林水産業の概要」](https://www.maff.go.jp/j/kanbo/tiho/todouhuken_gaiyou2022.html) を参照しています。道東の酪農の例は [北海道農政事務所「センサスからみた北海道農業」](https://www.maff.go.jp/hokkaido/toukei/kikaku/gurafu_gaiyou/sensasu-syuuraku/attach/pdf/sensasu-syuuraku-13.pdf) に基づきます。
